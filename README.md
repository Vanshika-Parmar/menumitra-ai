# 🍽️ MenuMitra AI

MenuMitra AI is an AI-powered multilingual menu assistant designed for local restaurants and small food businesses.

## 🚀 Features
- Add restaurant and dish details
- Enter dish prices
- Generate menu translations
- Support regional Indian languages
- Use Gemma AI locally through Ollama

## 🛠️ Tech Stack
- React + Vite
- Python + FastAPI
- Ollama
- Gemma 3 (4B)

## 💡 Why MenuMitra AI?
Many local restaurants need affordable ways to serve customers who speak different languages. MenuMitra AI aims to simplify multilingual menu creation using open-weight AI.

## 🔮 Future Plans
- Downloadable and printable menus
- More Indian languages
- Custom restaurant branding
